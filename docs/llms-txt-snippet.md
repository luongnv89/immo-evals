# llms.txt snippet for immo·evals

> **Where this goes:** `robots.txt`, `llms.txt`, and the root `sitemap.xml` are
> only read at the **domain root** (`https://luongnv.com/...`), which is served
> by a *different* repository (the personal site, `luongnv89.github.io`).
> Files placed in this `immo-evals` repo land at `/immo-evals/...`, a path no
> crawler fetches for those conventions. So add the snippets below to the **root
> site repo**, not here.

## 1. Append to the root `llms.txt`

The root `llms.txt` already lists OSS projects. Add `immo·evals` under
`## OSS Projects` (or a new `## Apps` section):

```markdown
- [immo·evals](https://luongnv.com/immo-evals/): Rapports acheteur pour annonces immobilières en France. Collez le lien d'une annonce (LeBonCoin, SeLoger, PAP, Bien'ici) et recevez un rapport : verdict prix au m² vs DVF, risques, coût total, angle de négociation. Showcase: https://luongnv.com/immo-evals/catalog.html
```
